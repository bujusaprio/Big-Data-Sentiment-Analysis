# Big-Data-Sentiment-Analysis
Product review sentiment analysis using PySpark, VADER, and machine learning.
# Big Data Sentiment Analysis

## Project Overview
This project analyzes product reviews using Apache PySpark and VADER sentiment analysis to identify positive, neutral, and negative customer opinions.

## Technologies Used
- Python
- Apache Spark (PySpark)
- Spark SQL
- VADER Sentiment Analysis
- Pandas
- Matplotlib and Seaborn
- Scikit-learn / Spark MLlib

## Project Workflow
1. Load and inspect the product review dataset.
2. Clean the data and handle missing values.
3. Combine review text and summaries.
4. Perform sentiment analysis using VADER.
5. Process text and extract features.
6. Analyze sentiment distributions and product ratings.
7. Train and evaluate machine learning classification models.
8. Visualize the results.

## Files
- `bda_final (2)(2)(1).ipynb` — project notebook.
- `data5.csv` — product review dataset.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries and Apache Spark dependencies.
3. Open the notebook in Google Colab or Jupyter Notebook.
4. Upload `data5.csv` to the notebook environment.
5. Run the notebook cells in order.

## Objective
To analyze customer feedback at scale and understand product sentiment using big data processing and machine learning.

## Results
The notebook includes sentiment analysis, visualizations, and model evaluation. Refer to the notebook for the reported evaluation results.
